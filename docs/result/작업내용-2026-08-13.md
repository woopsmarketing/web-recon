  (키 값은 어디에도 출력/기록하지 않음)

## 발생한 문제

- pnpm 11에서 transitive dependency `esbuild`의 install script가 기본 차단되어
  `[ERR_PNPM_IGNORED_BUILDS]` 경고 발생 → `pnpm exec` 래퍼의 deps-status 체크가
  non-zero로 실패.
  - 해결: `pnpm-workspace.yaml`에 `onlyBuiltDependencies: [esbuild]` 및
    supply-chain 정책 훅이 요구한 `allowBuilds: { esbuild: true }` 명시.
    재설치 후 esbuild postinstall 정상 수행, 경고/에러 해소.
- 그 외 문제 없음.

## 기술적 결정

- **`type: module` + NodeNext**: 최신 ESM 기준. TS import에는 `.js` 확장자 사용
  (`./config/env.js`) — NodeNext 규칙.
- **Phase 1에서 `FIRECRAWL_API_KEY`는 optional**: 키 없이도 CLI/smoke test가
  동작하도록 zod 스키마에서 `.optional()` 처리. Phase 2(Discovery Adapter)
  구현 시 required로 승격 예정.
- **Firecrawl은 아직 코드에 결합하지 않음**: import 가능성만 확인. 향후 Adapter로
  분리 예정 (ROADMAP Phase 2).
- **smoke test는 `scripts/`에 배치**: `src/` 모듈 디렉터리를 실제 기능 없이
  깨끗하게 유지하기 위함.
- **git 미초기화**: 현재 디렉터리는 git 저장소가 아님. 이번 Task 범위가
  아니어서 `git init`은 수행하지 않음 (`.gitignore`는 준비 완료).
