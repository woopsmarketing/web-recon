# 04 — 사용자 질의 4건 매칭 평가

판정 기준은 "현재 데이터(8건)만으로 **올바른** 포트폴리오를 설명 가능하게 고를 수 있는가"다. NL 파서는 존재하지 않으므로(`01-filter-contract.md` "Not built") 두 가지 경로로 확인했다.

- (a) 기존 `ProjectFilter`에 문장을 그대로 넣은 경우
- (b) 사람이 구조화한 필터로 바꿔 넣은 경우

증거: `evidence/project-filter-probe.txt`, `evidence/text-evidence-and-query-sim.txt`

## Q1. "34평 아파트인데 깔끔한 화이트톤" → **READY**

| 축 | 데이터 | 결과 |
|---|---|---|
| 34평 | area.value 8/8, supply (관례와 일치) | 정확히 34: bi-01, bi-06. 30평대: bi-01, bi-04, bi-06 |
| 아파트 | **유형 필드 없음**. 텍스트 "아파트"는 6/8이고, bi-04·bi-06은 어디에도 없다. bi-02는 body에만 있어 검색 대상 밖이다. | keyword로 쓰면 bi-06이 빠진다(area 30 + style 화이트 + keyword 아파트 → bi-01만). 비필터어로 다뤄야 한다. |
| 깔끔한 | literal 0/8 | 미니멀로 매핑하면 bi-01, bi-06 (매핑 여부와 무관하게 결과 동일) |
| 화이트톤 | keyword 화이트 | 34평 ∩ 화이트 = bi-01, bi-06 |

- (a) 문장 그대로 → 0건. (b) `34평 화이트` 또는 area 30 + style 화이트 → bi-01, bi-06 (+bi-04).
- 설명 가능한 순위: bi-01(전체 리모델링, 화이트+미니멀, 34평 정확) > bi-06(현관·거실만 한 부분 공사) > bi-04(32평, 주방·욕실만).
- READY인 근거: 모든 축이 구조화 데이터로 표현된다. 결과가 "깔끔" 매핑 여부에 좌우되지 않는다.
- 조건: "화이트톤→화이트" 정규화, "아파트"를 필터에서 제외.

## Q2. "24평에 2천만원 정도" → **NOT_READY** (평형 축만 READY)

| 축 | 데이터 | 결과 |
|---|---|---|
| 24평 | area 정확 | bi-02 (20평대: bi-02, bi-05) |
| 2천만원(총액) | **총액 필드 없음**. pricePerArea 6/8, 부분 공사 0/2 | 평당가로 역산하면 83.3만/평 → "180만 미만" 버킷 → 20평대 0건 |

- 파생 총액(평당가 × 평수): bi-02 5,760만(예산의 2.9배)이 최소 근접이다. 전체 6건이 5,130만~1억 3,440만으로, 2천만 ±30% 안에 드는 건은 0이다.
- 2천만 원대에 맞을 수 있는 유일한 후보는 부분 공사 bi-04와 bi-06(각 2주)인데, **가격이 없어서** 판단할 수 없다.
- bi-02를 "24평 사례"로 내밀면 약 3배 예산의 사례를 추천하게 되어 **오매칭**이다. 데이터로 할 수 있는 말은 "24평 전체 리모델링 사례는 평당 240만 원(추정 총 5,760만 원)"이라는 정직한 음성 응답뿐이다.
- 부족한 것: 총액·가격대, 포함 범위, 부분 공사의 가격.

## Q3. "30평대 모던한 느낌" → **PARTIAL**

| 축 | 데이터 | 결과 |
|---|---|---|
| 30평대 | 버킷 "30" | bi-01, bi-04, bi-06 |
| 모던한 | keyword 모던 3건. 텍스트 근거 0 | 30평대 ∩ 모던 = **bi-04 1건** (주방·욕실만 한 부분 리뉴얼) |

- (a) 문장 그대로 → 0건. style "모던한"(미정규화) → 조건이 조용히 빠져 **8건 전부** 반환된다.
- 매칭은 되지만 품질이 약하다.
  - 유일한 결과가 집 전체의 "느낌"이 아니라 주방·욕실 공사다.
  - "모던"은 근거 텍스트가 없는 큐레이션 태그라 설명할 수 없다.
  - 화이트·미니멀인 bi-01·bi-06을 "모던"에 넣을지는 **스타일 분류 결정**이 필요하다. 단순 동의어 매핑으로 해결되지 않는다(느슨하게 매핑하면 bi-01, bi-04, bi-06).

## Q4. "욕실이랑 주방만 하고 싶어요" → **READY**

| 축 | 데이터 | 결과 |
|---|---|---|
| 주방+욕실 | category kitchen-bath "주방·욕실 리뉴얼" | bi-04 |
| "만"(한정) | scope {주방, 공용 욕실, 안방 욕실} | 정규화 후 ⊆ {주방, 욕실} → bi-04만 |

- naive exact 부분집합 → 0건(공용/안방 욕실 때문). "포함"으로 매칭하면 bi-01·02·04·07이 나와 "만"의 의미가 깨진다.
- 보강 근거: bi-04 summary "두 곳만 골라 2주", 유일한 before/after 사진(주방·욕실 각 1쌍), 인용문 "살면서 진행".
- 한계: 후보가 1건뿐이고, 가격이 없어 "얼마?" 후속 질문에 답할 수 없다.
