# 03 — Source vs Clone geometry (live browser, `/`)

Measured with `getBoundingClientRect()` on the **live source** (`https://apartmentary.com/`)
and the clone (`next start` on :3212) in the same Playwright/Chromium, viewport height
1000, after a full lazy-load scroll. The clone DOM is 1:1 with the source tree, so every
region is addressed by the **same structural path** from the page root
(`.css-8atqhb` ↔ `[data-wr-node=n000005]`) — no heuristics.

- BEFORE = clone as delivered by the previous wide-desktop fix (backup of the CSS taken
  before any change in this task).
- AFTER = clone after this task.
- Tolerance: 3px for x/width, 8px for height.
- `≈ glyph` = heading `<p>` intrinsic text width differs by a constant −26…−31px at
  every width (x is identical) → clone font metrics, not layout.
- Full per-width table incl. heights, all 36 regions and text anchors:
  `evidence/geometry-table-full.md`; raw JSON: `evidence/*-geometry.json`.
