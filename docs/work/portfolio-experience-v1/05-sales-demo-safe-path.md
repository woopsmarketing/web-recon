`node --disable-warning=ExperimentalWarning --env-file-if-exists=.env.local scripts/data-truth-live-e2e.ts --only=safe-path` 이다.
AI 문장은 매번 조금씩 다르다. 카드 · 배지 · 이미지 · 사실은 결정론이라 같다.

- 운영 데이터는 8건(bi-01 … bi-08)이다. bi-09 … bi-19 는 사이트 · 문서 · BoostChat 어디에도 없다(04 감사).

  실제 시공 기록이 아니고, 사진은 record 마다 따로 생성한 AI 데모 이미지다. 영상은 "서비스 시연" 으로 소개한다.

## 2. 이 경로에 나오는 사례 — 왜 쓸 수 있고 무엇이 보이는가

**bi-04 · 32평 주방·욕실 중심 리뉴얼** (`/portfolio/buk-32py-kitchen-bathroom-renewal`)

- 왜 괜찮은가: step-6 에서 작성한 데모 정식 사례(canonical)다. 자기 brief · 사실 · 촬영 목록이 있고, 이 record 용으로 생성한
  이미지만 쓴다. `04-record-truth-audit.md` §0, `03-media-truth-audit.md`(bi-04 cover = 자기 갤러리)에 근거가 있다.
- 사실: 대구 북구 · 아파트 · 공급 32평 · 부분 리모델링 · 공사 범위 주방 · 욕실 · 스타일 화이트 · 모던 · **가격 없음**.
- 이미지 4장(갤러리 순서):
  1. 화이트 하부장과 슬림 후드로 바꾼 주방
  2. 언더마운트 싱크볼과 무광 니켈 수전
  3. 큰 규격 타일과 유리 파티션으로 바꾼 공용 욕실
  4. 욕조를 유지한 안방 욕실

이 경로에서 [요청과 같은 사례] 배지가 붙는 카드는 A(bi-04) 하나뿐이고, 평형 · 지역 · 공사 범위가 모두 요청과 맞는다.

## 3. 대안 구간 — 이미지가 가장 많은 bi-01 을 보여 주고 싶을 때

메시지 **"34평 아파트 화이트톤으로 전체 리모델링하고 싶어요"** 를 보내면 A = bi-01 · 수성 화이트 34평 아파트 리모델링
[요청과 같은 사례]가 나온다. Viewer 에 이미지 12장, 상세 페이지에 13장이 있고, 평당 공사비는 290만 원이다.

**주의:** 같은 결과의 B = bi-07 · 19평 소형 아파트 화이트 미니멀 리모델링에도 [요청과 같은 사례] 배지가 붙는다. 배지는
공사 범위(전체 리모델링)가 같다는 뜻이고 평형은 보지 않는다(matcher 계약, 이번 작업 이전부터 그렇다). AI 문장은 평형을
정확히 말하지만 배지만 보면 오해할 수 있다. 영상에서는 B 를 확대하거나 설명하지 않는다.
